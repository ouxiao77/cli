# 科研论文工作台 · OK 镜研究

统一管理：数据清洗 → 分组 → 统计分析 → 图表 → 论文写作。

当前为 **v0 仓库骨架**：可以初始化本地工作目录、检查配置、记录研究规则和后续任务。清洗、分组、统计及论文自动生成功能尚未实现；这里没有患者数据，也没有研究结果。

## 第一次使用（Mac）

1. 在 Codex 中打开本仓库及工作分支；先阅读本说明和 [任务清单](docs/TASKS.md)。
2. 确认电脑已安装 Python 3，在仓库目录的终端运行：

   ```bash
   python3 scripts/workbench.py init
   python3 scripts/workbench.py check
   ```

   第一条创建本地文件夹和 `config/project.local.json`，已有文件会保留。第二条检查骨架及配置，不执行研究分析。首次没有数据时会明确提示“尚未配置数据”。本阶段不需要安装 R 包。
3. 后续接入数据时，将经授权的原始 Excel **副本**放入本机 `data/raw/`，在本地配置中填写相对文件路径。工作簿和“分析就绪_宽表”工作表的真实性、列名及内容核查属于下一阶段。
4. 接下来可直接对 Codex 说：

   > 请阅读 README、docs/PROTOCOL.md 和 docs/TASKS.md，完成阶段 2 的数据盘点与核查。以我指定的“分析就绪_宽表”为源，只读原始数据，保留研究ID，先报告实际列名、缺失、重复、样本流向及待确认项；本阶段不做组间比较或统计建模。

若提示找不到 `python3`，可把提示发给 Codex，先完成 Python 3 环境设置。不要将患者文件上传到公开仓库。

## 目录与用途

| 位置 | 用途 | 本阶段状态 |
|---|---|---|
| `docs/` | 仓库盘点、研究约定、任务与回滚说明 | 已建立 |
| `config/project.example.json` | 可公开的配置示例 | 已建立 |
| `config/project.local.json` | 本机真实路径及配置 | 初始化生成，不纳入版本控制 |
| `templates/` | 数据字典、核查决定、结果溯源的空白模板 | 已建立，仅有表头 |
| `data/raw/` | 原始数据副本，只读使用 | 初始化生成，本地保存 |
| `data/interim/`、`data/processed/` | 中间数据、分析就绪数据 | 初始化生成，本地保存 |
| `scripts/workbench.py` | 初始化与配置检查入口 | 可运行 |
| `scripts/R/` | 按清洗、分组、分析、图表分开的 R 模块 | 仅模块规划 |
| `outputs/qc/`、`tables/`、`figures/`、`reports/` | 核查、表格、图片、报告（均位于 outputs 下） | 初始化生成，本地保存 |
| `outputs/logs/` | 后续运行日志 | 初始化生成，本地保存 |
| `manuscript/` | 论文结构及后续中英文草稿 | 已建立说明 |
| `references/` | 已核实的文献信息与引用 | 已建立说明 |

Git 不保存空目录，因此本地数据和输出目录由 `init` 创建。

## 本研究的起点

- 主要结局围绕眼轴；眼轴时间点为 0、6、12 月，不建立 1 月眼轴。
- 年龄、既往近视管理史、光学区、阿托品暴露各自保留；组合编码只用于展示。
- 主分析拟比较 5.0 与 5.5 mm，6.0 mm 作为拓展。阿托品排除规则、缺失暴露处理和分析队列需在真实数据中核实。
- 裸眼视力可另设 1 月 ≥0.8 的达标结局，须确认量表与可用数据。
- 所有研究数字必须来自实际数据。历史预期人数不能作为强制筛选目标。详见 [研究约定](docs/PROTOCOL.md)。

## 保存、审阅和回滚

本仓库当前公开。只提交代码、规则及不含个人信息的模板；本地数据、输出、真实配置和论文草稿默认忽略。`.gitignore` 不会保护已被 Git 跟踪的文件，也不能代替提交前检查。

本次分为“文档与目录约定”和“可运行入口及空白模板”两个提交，在独立分支审阅，不直接修改 `main`。查看 [原始盘点](docs/INVENTORY.md)、[阶段任务](docs/TASKS.md) 与 [回滚方法](docs/ROLLBACK.md)。
