# 后续 R 模块位置

本阶段不包含可执行的清洗或统计模型。接入真实数据并确认规则后按顺序添加：

| 拟定文件 | 输入 → 输出 |
|---|---|
| `01_import_qc.R` | 原始宽表 → 只读盘点与核查报告 |
| `02_clean.R` | 核实规则 → 清洗宽表及变更记录 |
| `03_group.R` | 清洗宽表 → 独立分组、队列标志、0/6/12长表 |
| `04_analyze.R` | 锁定计划和分析数据 → 估计结果及诊断 |
| `05_visualize.R` | 已核验结果 → 论文表图及溯源清单 |

上述文件尚未创建，避免占位脚本被误当成完成的分析。R 和包环境将在统计模块阶段通过版本锁定文件固定。
